These are two correlated boundaries of one BEQ-19 mechanism, not independent failure families.
Both isolated captures expose the same selected dock-dispatch component, inherited button route,
ordinary typed snapshot, optional queued reservation shape, .NET byte-channel sink, default encoder
configuration and unrelated calibration exporter. Only the queued writer operation differs.
This is synthetic batching/projection code, not a renamed or copied vendor fixture.

The common criterion and worksheet are staged identically to baseline and skill-present arms.
Neither controller code, expected statuses, source bindings, integrity controls nor the sibling
capture is staged. No native report producer, historical key, runtime/browser probe or skill
activation is needed or rewarded. Application-controlled IDs do not establish hostile input.

The program grader binds source/configuration bytes, checks complete structured relationships
(entry, branch, projection, scalar helper, actual writer and send sink), and requires quotations
covering their source anchors. It accepts reordered path records, namespace-qualified APIs and
coherent broad source ranges. These fixed-graph checks do not prove arbitrary prose semantics:
the independent outcome prompt rubric also evaluates the natural explanation, actual reachability,
ordinary-path facts and bounded conclusion, without requiring magic wording.

Legitimate assessor abstention is an outcome failure when complete source settles the criterion,
not an infrastructure exception. Omitted/mutated fixture bytes or mismatched controller bindings
are instrument errors. Incorrect labels, guessed/fabricated relationships, irrelevant quotes,
unreachable-as-reachable allegations, wrong sinks and nonempty nonsense structured explanations
are outcome failures.
